Features

它解决什么问题

战网客户端本身只记一串"记住密码"的邮箱，不记这个邮箱属于哪个区服，更没有一键切号； 频繁切换账号还会被浏览器验证码烦到。这个工具把这几件事都补上。

⇄按区服管理账号

国服 / 美服 / 欧服 / 亚服 / 台服分别成组，同一个邮箱可以在多个区服各留一条记录。 切换时自动关闭战网、改配置、带 --setregion 重启。

💾本地状态快照

在账号登录还新鲜时，把战网客户端的本地状态存一份。 切换时自动先更新源账号的快照、再恢复目标账号的快照， 让客户端直接向服务端续期，减少浏览器验证码。 同一邮箱在多个区服各存一份，互不覆盖。

🛡改配置前自动备份

Battle.net.config 在写入前会先复制一份 .backup， 写入失败也能原样恢复，不动战网自身的账号数据。

✂一键拔线 / 断网

选定任意 exe，点一下立即断网，可同时静音该应用的声音； 默认 3 秒后自动恢复，时长 1 ~ 3600 秒可调。基于 Windows 防火墙出站规则，不需要驱动。

⌨GUI / CLI 双份

图形界面和命令行共用同一份账号本、设置与快照： GUI 里改过的路径、CLI 里加过的账号或保存的快照，互相都能看到。

📦便携版 / 绿色版友好

战网没装在默认位置也能用：手动指定 Battle.net.exe 与 Battle.net.config 的完整路径即可，配置一次 GUI 和 CLI 都生效。

🔓不需要时可以不提权

用不到"一键拔线"就在设置里关掉，GUI 启动不再弹 UAC，只保留账号切换。

数据都放在本地： %APPDATA%\BattleNetSwitcher\accounts.json 记录"邮箱 ↔ 区服"， config.json 记录全局设置， Snapshots\<邮箱>__<区服>\ 保存本地状态快照。 程序不联网、不上传，也不修改战网账号本身。

💾本地状态快照是怎么工作的

战网的登录凭证是 Windows DPAPI 加密的 blob， 存在注册表 HKCU\...\Battle.net\UnifiedAuth\ 下。 客户端会主动清理"不活跃"的旧凭证 —— 离开某账号越久，越可能被删， 切回去就只能走网页验证、频繁弹验证码。

快照的思路是：在凭证还新鲜时备份一份，切换时写回去， 让客户端读到"已验证过"的本地状态，直接向服务端续期。

切换 A → B 时工具会：

  • 关闭战网（优雅退出，超时才强杀）
  • 自动为 A 更新快照 —— 刚下线的状态最新鲜
  • 恢复 B 的快照（若存在）
  • 带 --setregion 启动客户端

同一邮箱在国服与美服各有独立快照，切换时按 (邮箱, 区服) 精确匹配。

→ 去 UI 模拟 里点"更新当前快照"或"切换"账号，可以看到完整的保存/恢复日志。

🔌为什么需要"一键拔线"

有些操作需要让某个程序在几秒内彻底断网，但又不想拔路由器、 也不想影响其它正在联网的软件：

  • 游戏里卡在某个结算 / 掉线重连，想复现或绕过它
  • 切账号、换区服前，先把旧会话掐断，避免状态残留
  • 某个应用在后台偷偷联网，只想让它安静几秒

工具的做法是给指定的 exe 加一条防火墙出站阻止规则， 到期自动删除，全程只影响这一个程序：

  • 勾一下同时静音，连声音也一起掐掉，画面卡住但不吵人
  • 秒数想设多久设多久，1 ~ 3600 秒
  • 用不到这个功能可以整个关掉，程序启动就不再请求管理员权限

→ 去 UI 模拟 的"一键拔线"页点一下，能看到完整的倒计时与自动恢复过程。

Details

用起来你会关心的几件事

  • 首次打开就能用：本地还没有记录时，它会把你战网里已经"记住密码"的账号自动收进来， 不需要一个个手输。其它区服的账号用 add / "添加账号"补一次即可。
  • 首次登录仍需手动完成（含验证码）：这一步没法省 —— 快照只能省后续切换的验证。 登录成功、客户端就绪后，点一下"更新当前快照"，从此切来切去基本不再弹验证码。
  • 切换账号时自动更新源账号快照：切 A → B 的瞬间，工具会先为 A 更新快照， 因为它刚下线时的凭证是最新鲜的。不需要手动维护。
  • 同一邮箱可以在多个区服各存一份快照：比如 player@example.com 在国服和美服 各有独立快照，切换时按 (邮箱, 区服) 精确匹配，互不覆盖。
  • 它只改两处内容：战网自己那份 Battle.net.config 里的 "默认登录账号"与"当前区服"，改之前先备份成 .backup； 不改密码、不解绑、不删除战网里的任何账号数据。
  • 不碰安装级密钥：整个流程从不触碰 EncryptionKey 与 CacheDatabase —— 破坏它们客户端会完全登录不了。
  • 列表里的 × 只删本地记录：不影响战网账号本身；该邮箱所有区服的快照也会一并删除。
  • 全程离线运行：没有账号上传、没有遥测；需要联通的只有两个动作 —— 读取本机战网路径、调用系统防火墙。
  • 只有"一键拔线"需要管理员权限：启用时启动会弹一次 UAC； 在【设置】里把它关掉，之后启动就再也不弹了。
  • 真的需要改防火墙："一键拔线"用的是 Windows 自带的 netsh 防火墙规则， 绝大多数安全软件不管它；万一弹出提示，放行一次就好。
  • 连美服 / 欧服 / 亚服建议开加速器：这是网络线路问题，跟工具无关。
  • 各区服的账号是独立的：战网本身的规则，同一个邮箱要在某个区服玩， 得先在该区服有账号。
  • 快照不能跨 Windows 用户 / 换机器用：凭证是 DPAPI 加密的 blob， 绑定原用户与原机器，换环境解不开 —— 这是系统限制，不是工具的限制。
