Battle.net account switcher

Windows 10 / 11 · .NET 8

战网账号快速切换
+ 应用一键拔线

按区服分组管理战网账号，一键切号并自动带上 --setregion 重启客户端； 需要时还能对任意应用一键拔线——一条防火墙规则断它的网、顺手静音，默认 3 秒后自动恢复。 全程离线运行，不联网、不上传任何数据。

Features

它解决什么问题

战网客户端本身只记一串"记住密码"的邮箱，不记这个邮箱属于哪个区服，更没有一键切号。 这个工具把这两件事都补上。

⇄按区服管理账号

国服 / 美服 / 欧服 / 亚服 / 台服分别成组，同一个邮箱可以在多个区服各留一条记录。 切换时自动关闭战网、改配置、带 --setregion 重启。

🛡改配置前自动备份

Battle.net.config 在写入前会先复制一份 .backup， 写入失败也能原样恢复，不动战网自身的账号数据。

✂一键拔线 / 断网

选定任意 exe，点一下立即断网，可同时静音该应用的声音； 默认 3 秒后自动恢复，时长 1 ~ 3600 秒可调。基于 Windows 防火墙出站规则，不需要驱动。

⌨GUI / CLI 双份

图形界面和命令行共用同一份账号本与设置： GUI 里改过的路径、CLI 里加过的账号，互相都能看到。

📦便携版 / 绿色版友好

战网没装在默认位置也能用：手动指定 Battle.net.exe 与 Battle.net.config 的完整路径即可，配置一次 GUI 和 CLI 都生效。

🔓不需要时可以不提权

用不到"一键拔线"就在设置里关掉，GUI 启动不再弹 UAC，只保留账号切换。

数据都放在本地： %APPDATA%\BattleNetSwitcher\accounts.json 记录"邮箱 ↔ 区服"， config.json 记录全局设置。 程序不联网、不上传，也不修改战网账号本身。

🔌为什么需要"一键拔线"

有些操作需要让某个程序在几秒内彻底断网，但又不想拔路由器、 也不想影响其它正在联网的软件：

  • 游戏里卡在某个结算 / 掉线重连，想复现或绕过它
  • 切账号、换区服前，先把旧会话掐断，避免状态残留
  • 某个应用在后台偷偷联网，只想让它安静几秒

工具的做法是给指定的 exe 加一条防火墙出站阻止规则， 到期自动删除，全程只影响这一个程序：

  • 勾一下同时静音，连声音也一起掐掉，画面卡住但不吵人
  • 秒数想设多久设多久，1 ~ 3600 秒
  • 用不到这个功能可以整个关掉，程序启动就不再请求管理员权限

→ 去 UI 模拟 的"一键拔线"页点一下，能看到完整的倒计时与自动恢复过程。

Details

用起来你会关心的几件事

  • 首次打开就能用：本地还没有记录时，它会把你战网里已经"记住密码"的账号自动收进来， 不需要一个个手输。其它区服的账号用 add / "添加账号"补一次即可。
  • 它只改两处内容：战网自己那份 Battle.net.config 里的 "默认登录账号"与"当前区服"，改之前先备份成 .backup； 不改密码、不解绑、不删除战网里的任何账号数据。
  • 列表里的 × 只删本地记录：不影响战网账号本身。
  • 全程离线运行：没有账号上传、没有遥测；需要联通的只有两个动作 —— 读取本机战网路径、调用系统防火墙。
  • 只有"一键拔线"需要管理员权限：启用时启动会弹一次 UAC； 在【设置】里把它关掉，之后启动就再也不弹了。
  • 真的需要改防火墙："一键拔线"用的是 Windows 自带的 netsh 防火墙规则， 绝大多数安全软件不管它；万一弹出提示，放行一次就好。
  • 连美服 / 欧服 / 亚服建议开加速器：这是网络线路问题，跟工具无关。
  • 各区服的账号是独立的：战网本身的规则，同一个邮箱要在某个区服玩， 得先在该区服有账号。
